# harsh-personal-website

Personal site and blog for [Harsh Thomare](https://harshthomare.github.io/).

**Live site:** [harshthomare.github.io](https://harshthomare.github.io/)

The deploy build takes its base URL from GitHub Pages (`steps.pages.outputs.base_url`). Because this repository is `HarshThomare.github.io`, that value is the site root.

Built with [Hugo](https://gohugo.io/) and the [PaperMod](https://github.com/adityatelange/hugo-PaperMod) theme.

## Local development

```bash
git clone --recurse-submodules https://github.com/HarshThomare/HarshThomare.github.io.git
cd HarshThomare.github.io
hugo server
```

Open [http://localhost:1313](http://localhost:1313).
